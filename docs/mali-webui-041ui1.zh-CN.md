# Mali 首次绑定开关显示修复（webui1）

2026-10-18。修复已部署到当前设备的 Mali Global，用户随后确认相关项显示正常。
Decode Stack 未修改。

原因：Mali 的旧 CSS 仅为 whole／dvfs 两个 ID 定义轨道和滑块，遗漏 cold。
现在按 role=switch 共用样式，避免新增开关漏配；样式和翻译 URL 增加修订标记，
便于 WebView 刷新资源。首次绑定说明同步标为限定固件实验功能。

31 项浏览器检查通过，包括三个开关尺寸、开启／关闭滑块位置、当前状态与
重启后状态的区分及窄屏布局。设备校验确认安装后的模块文件清单一致，
首次绑定当前／重启后均为开启，无待重启，Zygisk 双 ABI／LSPosed 检查通过。
boot 哈希及三个图形 PID 与修复前相同。未切换驱动或重新执行播放性能基线。
浏览器脚本使用模拟桥；设备检查及用户显示反馈分别记录，不混作原生 WebView 自动化。

安装包为 0.4.1-test2 的 UI 修订，模块运行版本号保持不变，修订记录见
WEBUI_FIX.json。驱动、boot 加载器、状态桥、选择与回退策略均保留原字节。
包内旧运行验收文档沿用基础包快照；Zygisk 运行修复结论见
mali-zygisk-repair-041.zh-CN.md。本修订仍为实验包。

设备保留修改前的三项 WebUI 资源及原校验清单；整包停用／首次绑定关闭的
重启回退行为不变。无需为样式修复重启盒子，重新打开 WebUI 即可读取更新资源。

# v0.8.6 — 系统帧率保留与正式版整合

Decode Stack 0.8.6、Mali Global 0.4.2、LSPosed 客户端 0.3.7 为正式包；Frame Guard 0.1.1 和可选 PanVK Test8.1 原字节携带。项目版本标识完整快照，各组件保留独立版本。

安装建议更新：Frame Guard 已退出当前推荐组合。当前已验收配置不再需要固定 60Hz 的旧规避；已发布附件仅保留作历史回退参考。旧安装移除前须恢复它保存的系统刷新率限制，新安装无需再装。当前组件选择见 [下载页](../DOWNLOADS.md)。

Auto 下的指定 Exo 短黑场景已通过用户实屏反馈。原先只拦截旧 Binder 入口的 test19 未命中；正式版在共同 Layer 帧率入口保留同一视频的有效请求，实际记录到清除请求继续采用 24Hz。新的片源帧率仍更新，隐藏／删除图层由原系统排除。QMS 内核与 HWC 保留原配套，本次没有新增 QMS 字段试验，也没有改为应用专用帧率钩子或固定 60Hz。

两套 WebUI 及客户端同步中英文正式说明，清理已验收功能的候选标签，明确每项用途、依赖、回退及尚未覆盖范围。WebUI 资源更新版本号避免旧说明缓存。新包保留已验收原生库、驱动及 P010 客户端执行代码；FFmpeg 只清理只读编译信息中的本机目录并更新哈希，未改解码执行字节。更新保留既有设置和模块启停状态。

完整安装检查补齐了设置修复已经挂载时读取私有原件的升级路径，以及帧率保留开启／QMS 关闭时的精确 Mali 配套识别。未知原件、旧启动收据、混合库或缺失选择仍拒绝。原件和生成的 services.jar/OAT 只在设备本地保存，不进入公开包。

低层功能仍限精确固件、ABI、内核及启动配套。未准备私有启动适配的设备不默认开启首次绑定或 QMS；公开包不含 boot、原固件、Mali 闭源库或 CSF 固件。分项关闭并重启恢复对应旧路径；整包关闭并重启恢复原固件路径。

验收限已记录的片源、应用与接收端。完整 HDR 色彩校准、所有应用／电视、不同帧率换片、真正分辨率／HDR 格式切换和长期游戏性能没有因改正式版而自动通过。PanVK 保持可选实验性质。Auto 内容匹配时保持 Frame Guard 关闭。

临时请求追踪已关闭；默认无逐帧日志或新增轮询线程。本版对暂停请求的处理仅随帧率请求事件执行。完整记录见 `docs/validation/decode-refresh-session-086.json`。

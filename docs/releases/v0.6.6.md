## Language controls / 切换入口

- **Decode Stack:** open KsuWebUI → RK3588 Decode Stack, then use **English / 中文** at the top. All descriptions, dependencies, backend names, states, saved-change messages and errors switch immediately. First use follows browser language, with English fallback. Language switching sends no root command and changes no component setting.
- **LSPosed plugin:** open the plugin settings and use **English / 中文**. The choice is stored separately from playback preferences. System locale controls the launcher name and LSPosed description; the manual choice controls the settings page. Same package ID and signing certificate allow an in-place update.
- **Mali / Frame Guard:** module descriptions, installer and Action/CLI messages already support English. Neither has a separate graphical settings page; no need to reinstall their unchanged packages.

Decode Stack WebUI 与插件设置均有语言按钮并记忆选择；不改解码开关、原三个修复选项或 LSPosed 作用域。WebUI 清除宿主数据后会清除语言偏好；存储不可用时仍可临时切换。全部网页资源离线携带。

## Validation and scope / 验证范围

- **48 browser assertions** pass, including catalog parity, remembered language, root-command isolation, translated pending/error states, English layout, storage failure and existing dependency/version controls.
- **12 native resource pairs**, **104 English module-facing lines**, and **4 geometry unit tests** pass.
- Actual KsuWebUI and native plugin settings display both languages and remember the choice after reopening. Original hook preferences are exact, and WebUI language changes leave all module choices unchanged.
- All **26 decoder ELF files** and **192 component/shell files** match 0.6.5. **16 existing hook/geometry compiled classes** match the previous build byte-for-byte. Yamby native libraries, boot and kernel remain unchanged. Candidate boot checks pass with no pending reboot after testing.

本次仅语言与显示更新，没有新增播放功能，也未重做完整格式／精度矩阵。原固件兼容范围、回退、已知播放与安兔兔限制不变；不新增 HDR10+ HDMI 或杜比能力，不降低画质。

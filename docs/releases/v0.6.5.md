## 界面与操作

- **Codec2 后端版本**单选：旧后端（0.4.0 路径）／1.14.3 SIMD／1.14.16。原来两个 SDK 版本开关移除，只会加载其中一个版本。
- 下级接在依赖项下面，用缩进和连接线显示。Codec2 同时列出其额外 RGA 依赖。
- **关闭父项：保留下级原选择，变灰表示暂不生效。重新开启父项后恢复。**
- 开启子项时补齐依赖，需要新版后端的 AV1 原生输出／AFBC 会联动选用 1.14.16，并显示联动项目。
- 手动选择后端也会补齐 Codec2／MPP／RGA。较旧后端暂时抑制不适用功能，不清除原选择。
- 分项编辑不会擅自启用已停用的整包；所有变更仍需重启，当前／重启后状态分开显示。

安装 ZIP 并重启，打开 **KsuWebUI → RK3588 Decode Stack**。版本与依赖在一次配置替换中提交；旧 CLI 单项命令仍保留，Action、自动恢复、启动装配和固件检查不变。

This complete release replaces two Codec2 version switches with one selector and nests dependent controls under prerequisites. Parent-off retains and grays child choices; parent-on restores them. Enabling a child atomically enables prerequisites and the required backend. Decoder ELF files and other installers are unchanged. All settings still require reboot; existing rollback remains.

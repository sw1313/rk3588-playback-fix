### 修正与验证

- 修正 G610 绘制辅助函数 GPU 地址被截为 32 位的问题。附一行 Mesa 源码补丁，
  以及哈希／ELF／指令严格校验的两条 AArch64 指令补丁；**不是完整重编译 Mesa**。
- 将三个工作队列放入同一 CSF 组的 CSI0／1／2，规避疑似跨组等待。真实命令、等待、
  完成信号和错误传播保留，组释放引用计数与 fd 清理齐全；没有修改系统内核或固件。
- 保留 geometryStreams、AFBC、精确 BC 解码和画质设置。Test7 额外提交同步已撤下，
  但 Android 帧交付桥仍要等真实 GPU fence，存在同步开销。

4480 组离线地址计算、编译 C 引擎 9000 次生命周期操作及失败／重试／隔离／清理
检查通过；设备 23 项几何、17 项变换反馈、AFBC 回读、地址专项回归通过。游戏运行
期间另有 10 次真实图形上下文生命周期检查通过。用户反馈人物、画面恢复，标题／
开始／触摸层**短测暂未闪退**。尚非长期稳定、全游戏或所有固件兼容结论。

仅实测 RK3588/G610、Android12/API32、Linux5.10.66 与已有配套 g18p0 内核／CSF。
测试游戏临时使用 JIT 对照，全局 CPU 设置未改；本 ZIP 不会设置 CPU 后端。
NCE 在系统驱动下也出现过停滞，因此当前 FPS **不是最终性能结果**。

### 安装与回退

退出游戏，在原版应用的 GPU 驱动管理中导入并选择
`rk3588-panvk-rc3-test8.1.zip`，再进入游戏。回退：退出游戏、选择“系统 GPU 驱动”、
重新进入。无需刷 boot、替换系统驱动或卸载现有模块；Yamby 和 LSPosed 不动。

## English

All four existing installers are carried byte-for-byte, alongside optional
**PanVK RC3 Test8.1**, imported in **the tested application's GPU driver manager**, not
Magisk. Test8.1 updates documentation/licenses/metadata only; both runtime
libraries match locally tested Test8. Adapter source, offline tests, public
upstream pins and build instructions are included. The G610 address fix is
a strict two-instruction binary counterpart of the included one-line source
patch, **not a complete Mesa rebuild**.

The single-CSG / three-CSI workaround improved the short title/start/touch-
overlay retest. Cross-group waiting remains a provisional cause; long-run,
all-game and factory-kernel compatibility are unproven. Geometry streams,
exact BC, AFBC, quality and real completion waits remain. Test7's extra
submit-sync diagnostic is absent; the presentation bridge still waits on
real GPU fences. Tested on existing matched g18p0 KMD/CSF, Android12/API32,
RK3588/G610, Linux5.10.66. Per-game JIT was used for a separate CPU comparison;
this ZIP does not set CPU settings, and this is not a final FPS assessment.

Offline address cases (4480), compiled-engine lifecycle operations (9000),
40 native geometry/XFB cases, AFBC readback and 10 extra context lifecycles
passed, subject to the limits above. Rollback: stop the game, select **System
GPU Driver**, reopen it. No the tested application APK, system driver, firmware, boot,
Yamby or LSPosed changes. Original project code is MIT; upstream licenses
remain. Private logs, device identifiers, accounts, configuration, games,
keys and proprietary firmware are excluded from public source and assets.

## Included documents / 包内说明

LICENSE, NOTICE, OPEN_SOURCE.md, THIRD_PARTY_NOTICES.md, SOURCE_CODE.md,
SOURCE_CODE.zh-CN.md and exact-version OPEN_SOURCE.json are included in each
Magisk ZIP root and the APK's assets/open-source directory. Decode Stack keeps
all original component licenses and adds shared upstream/NDK notice copies.
Build scripts now stage the notices before integrity manifests automatically.

Release also contains a project source ZIP, manifest, validation and SHA256SUMS.
The source ZIP contains this repository, patches, build scripts and licenses;
it is not a complete Android SDK/BSP. Pinned public upstream source downloads
and private exact-firmware link inputs are documented separately. No closed
Mali driver, original firmware library, private key, media or raw device log
is included. Mali's separately licensed install-time download remains unchanged.

源码包含项目源码与补丁，完整上游来源、精确提交、工具链、四包构建方法及固件
链接输入限制均有说明。不上传闭源驱动、原厂固件库、私钥、影片或原始设备日志。
APK 继续使用原签名；自建包不提供私钥，证书不同不能直接覆盖发布包。

## Validation / 验证

- All four installers pass notice/provenance, archive safety and SHA256 checks.
- 26 decoder ELFs, 8 Mali interface/probe ELFs and all pre-existing control
  scripts/WebUI entries are unchanged from v0.6.6.
- 16 hook/geometry compiled classes are byte-identical; settings source and
  existing fixes are unchanged. Plugin signature matches the previous release.
- 4 geometry unit tests, 12 native language resource pairs and existing English
  message checks pass. This documentation update performs no new device install,
  playback/precision matrix or reboot test; historical runtime evidence remains
  attached to prior versions. Existing limitations and rollback behavior remain.
- Source and package privacy checks pass; public download hashes are checked
  after upload. / 源码、附件与包内文件均检查隐私，上传后核对公开下载校验值。

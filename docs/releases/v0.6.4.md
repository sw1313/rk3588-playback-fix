## 使用方式

在 Magisk 安装新版 Decode Stack ZIP 并重启，打开 **KsuWebUI → RK3588 Decode Stack**，按需授予 root 权限。无需更换 root 方案；Magisk 自身不内嵌 WebUI。

- 十四个分项开关按基础组件、Codec2／软件解码、十位／AV1、HDR 分组。
- 显示已保存选择、直接依赖、本次启动配置、重启后的有效配置和待重启／更新暂存状态。
- 依赖未满足时保留选择，恢复依赖后继续生效。改变后恢复原有效选择可取消不必要的待重启提示。
- 启动记录仅由实际 boot 阶段写入，防止把安装器准备的配置或旧启动配置误报为正在生效。旧版本无记录时显示未知并提示重启。
- 页面资源随模块离线携带，支持键盘焦点和窄屏；无 root 桥或操作失败时明确报错。

分项写入继续调用原 `mode-control.sh`，保留 CLI、Magisk 总开关、Action、依赖解析、升级暂存同步和自动回退。配置异常时仍可通过总开关停用整包。所有修改均需重启，不热替换库。

## 验证与边界

- Android 真机隔离 shell 测试 **78 项**通过；浏览器模拟回调交互测试 **16 项**通过。
- 实际 Android KsuWebUI 1.0（34）验证 MPP 关闭／恢复、依赖选择保留、整包开关、待重启提示，以及从原厂状态重新启用。
- 整包关闭并重启，**31 个系统文件恢复原厂哈希**；重新启用并重启，十四分项恢复、启动健康检查通过、待重启提示清除。
- 本地原始 AV1 4K60 十位 HDR 60 秒片源复测：**3597 输入／3597 渲染，零丢帧，正常 EOS**。使用已安装 SmartTube 的原版 ExoPlayer 引擎，不是完整网络播放界面的测试。
- **188 个组件与既有回退文件字节不变**；18 个 Yamby 原版库、LSPosed、全局 Mali、内核和 boot 保持不动。不降低精度、分辨率、码率或帧率。

本次没有重做全部格式精度矩阵，沿用 0.6.3 已记录的有限样本与边界。KSU API 兼容不代表整个固件专用挂载栈已在所有 KernelSU 设备验证。安兔兔完整剪辑提前 EOS 和图像特效退出异常仍未修复；未增加 HDMI HDR10+ 或杜比输出能力。

This complete release adds an offline KSU-compatible WebUI to Decode Stack. Saved selections, dependency suppression, actual boot state and pending reboot/update status are shown separately. Existing shell controls and rollback remain; decoder binaries and the other three installers are unchanged. Real Magisk/standalone-WebUI interaction, reboot rollback and local AV1 playback were verified.
